# Manifest of the proof-of-execution files

Every file of `results/` appears exactly once below, with the command that
produced it and what it shows. `make proof` checks this table against the
directory tree, regenerates `results/lint/` and writes
`proof_of_execution.tar.gz` (top folder `proof_of_execution/`). Commands are
copied from the `command:` line of each log, or taken from the scripts that
write the file. Paths such as `out/...` are the (git-ignored) output
directories of the runs; `data/cubes/...` are the cubes described in
`data/README.md`. How to read the files: [`RESULTS.md`](RESULTS.md).

All detection runs used commit `8fd110a` (the date-scaling sweep and the
textbook-defaults demo run: `cfb0fd0`, a scripts-only change; the co-registration
run: `1003e00`, whose co-registration code is unchanged since `6cf6c38`) on an RTX 4070 Laptop GPU
and an i9-14900HX (16 visible threads), see `logs/hardware.txt`. The unit-test logs
are produced from the final committed tree (see their `git_commit:` line).
